## What is it and how does it work?

Pokeflex is a simple website where you can create and display your own Pokémon team.

When you select one of the six circles, a search bar will appear where you can enter the name or Pokédex ID of the Pokémon you want to add. The circle's background color will automatically change depending on the Pokémon's type.

You can also click on the trainer sprite to switch between six different playable characters.

### Available characters
* Red from Pokémon FireRed & LeafGreen
* Leaf from Pokémon FireRed & LeafGreen
* Ethan from Pokémon HeartGold & SoulSilver
* Lyra from Pokémon HeartGold & SoulSilver
* Brendan from Pokémon Emerald
* May from Pokémon Emerald

The website also has background music, which can be turned on or off using the Music button.

The elements on the screen automatically resize depending on the size of the screen, making the website responsive.

## About the project

This project is still a work in progress, so some of the features mentioned above are not available yet.

Honestly, this project doesn't have much practical use, but that's kind of the point. I wanted to keep it simple and use it as a way to practice and learn.

This is also my first project, so I hope y'all enjoy it! ❤️
